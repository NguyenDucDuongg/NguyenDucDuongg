# BÀI 06 – XÂY DỰNG MODULE TÍNH KẾT QUẢ HỌC TẬP

**Họ tên:** Nguyễn Đức Dưỡng  
**Mã sinh viên:** CĐ-CNTT18B06

## 1. Yêu cầu bài thực hành

- Tạo module `xulyDiem.js` để tính điểm trung bình 3 môn.
- Xây dựng hàm xếp loại học tập.
- Sử dụng `module.exports` để xuất hàm.
- Sử dụng `require()` trong file `bai06.js`.
- Tạo dữ liệu 3 sinh viên và hiển thị kết quả trên Terminal.

## 2. Cách chạy chương trình

```bash
node bai06.js
```

## 3. Kết quả

Chương trình tính điểm trung bình và xếp loại học tập cho 3 sinh viên theo yêu cầu.

## 4. Hình ảnh minh chứng

- Ảnh 1: Nội dung file xulyDiem.js.
- Ảnh 2: Nội dung file bai06.js.
- Ảnh 3: Kết quả chạy chương trình.

## 5. Kết luận

Hoàn thành bài thực hành xây dựng Module tính kết quả học tập bằng Node.js.
